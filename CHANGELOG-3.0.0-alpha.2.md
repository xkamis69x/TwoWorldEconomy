# TwoWorldEconomy 3.0.0-alpha.2

- nowe komendy `/eco` dla portfela i banku,
- `give`, `take`, `set` i `balance` z autouzupełnianiem,
- natychmiastowe powiadamianie HubCore po zmianie salda,
- item portfela `$` w hotbarze, aktualizowany po każdej transakcji,
- kliknięcie PPM itemem otwiera bank,
- ochrona itemu przed przenoszeniem, wyrzuceniem i utratą po śmierci,
- GUI banku pozostaje otwarte i odświeża saldo po każdym kliknięciu,
- brak jakiegokolwiek własnego scoreboardu.
