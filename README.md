# TwoWorldEconomy 3.0.0-alpha.2

Ekonomia portfela i banku dla Paper 1.21.5 / Java 21.

## Komendy administratora

- `/eco balance <gracz>`
- `/eco give <gracz> <kwota>`
- `/eco take <gracz> <kwota>`
- `/eco set <gracz> <kwota>`
- `/eco bank balance <gracz>`
- `/eco bank give <gracz> <kwota>`
- `/eco bank take <gracz> <kwota>`
- `/eco bank set <gracz> <kwota>`

Uprawnienie: `twoworldeconomy.admin`.

## Ważne

Plugin nie ustawia scoreboardu. Należy usunąć starą wersję `TwoWorldEconomy-2.0.2.jar` i pozostawić tylko nowy JAR. Sidebar obsługuje HubCore 0.6.0-alpha.6.

Item portfela jest domyślnie w slocie 8 hotbara (`slot: 7`) i otwiera bank po kliknięciu PPM.
